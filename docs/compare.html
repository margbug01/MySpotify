HOW TO CHOOSE

哪一种更适合你？

适合选 MySpotify

嫌官方桌面端笨重占内存；想要原生 macOS/Windows 桌面悬浮歌词、网易云/LRCLIB 补全与中文翻译；看重开源零遥测、快速冷启动和 MV/播客逐字稿。

适合选官方客户端（或配 Spicetify）

刚需 Premium 离线下载、无损音质、Jam 协作、AI DJ、本地文件同步，或希望绝对零账号风险与完整官方支持。

适合选终端客户端（ncspot 等）

已有 Spotify Premium 账号，重度使用 Linux/SSH 纯键盘工作流，不需要封面视觉界面、MV 和桌面悬浮歌词，追求极致低内存。

FAQ

选型常见问题

为什么 MySpotify 比官方 Spotify 桌面端更省内存？

官方桌面端基于 CEF 内置了一套完整 Chromium 浏览器环境来渲染全部界面；MySpotify 使用 Go 与 MyGo 原生绘制全部界面，仅在播放加密音频时按需调用系统自带的 WebView2 或 WebKit DRM 模块，因此安装包小于 10 MB，仅浏览时约 190 MB，播放时增加约 60 MB。

MySpotify 和 Spicetify 有什么区别？

Spicetify 是对官方 Spotify 客户端注入主题与扩展的工具，仍需安装并运行官方 CEF 客户端，保留离线下载等官方能力；MySpotify 是完全独立的 Go 原生软件，无需安装官方客户端，体积和内存大幅降低，且原生内置桌面悬浮歌词、多源歌词补全和零遥测。

什么时候应该继续使用官方 Spotify 客户端？

如果你需要离线下载歌曲、无损音质、Jam 一起听、AI DJ、好友动态、本地音乐文件，或者完全不想承担第三方客户端的条款与封号风险，建议直接使用 Spotify 官方客户端。
